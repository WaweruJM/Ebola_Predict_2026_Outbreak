Solving ODEs with deSolve

deSolve is the standard R package for solving initial value problems in ordinary differential equations. It provides a unified interface to a wide range of numerical solvers, including the widely used lsoda.

The Standard Pattern

  1. Define a function that returns the derivatives of each state variable.
  2. Set initial conditions and parameter values.
  3. Call ode() with the state, times, function and parameters.

The SIR Model in deSolve Syntax

library(deSolve)

sir_model <- function(time, state, parms) {
  with(as.list(c(state, parms)), {
    N  <- S + I + R + D
    dS <- -beta * S * I / N
    dI <-  beta * S * I / N - (gamma + mu) * I
    dR <-  gamma * I
    dD <-  mu * I
    list(c(dS, dI, dR, dD))
  })
}
