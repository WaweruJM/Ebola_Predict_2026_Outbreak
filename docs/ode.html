Ordinary Differential Equations

Resource Library

Why ODEs Drive Compartmental Models

An ordinary differential equation (ODE) describes how a quantity changes with respect to a single independent variable — in our case, time. Epidemic compartments change continuously, so ODEs are the natural language for describing those flows.

The Basic Idea

An ODE has the form:

dS/dt = f(S, I, R, D, t)

which reads: "the rate of change of S with respect to time is some function f of the current compartment sizes and time." The SIR model is a system of such equations — one per compartment — solved simultaneously.

An Initial Value Problem

Every ODE system needs initial conditions:

S(0) = S₀    I(0) = I₀    R(0) = 0    D(0) = 0

In this portal, S₀ = N − I₀ where N = 20,000,000 and I₀ is the number of confirmed active cases on the first day of data.

Why There Is No Closed-Form Solution

Unlike simple ODEs from calculus, the SIR system is nonlinear (because of the S·I product). There is no analytical formula for S(t), I(t), etc. Therefore we must integrate numerically — which is what the deSolve package in R does.

The Method of Numerical Integration

Numerical solvers step forward in small time increments. At each step they approximate the derivative using the equations and update the state:

S(t + h) ≈ S(t) + h · f(S(t), t)

Production-grade solvers (like lsoda in deSolve) use adaptive step sizes and higher-order methods for accuracy and stability.

Stiffness and Stability

When compartments differ in scale by many orders of magnitude, the ODE system is called stiff. lsoda automatically switches between stiff and non-stiff methods, which is why it is the default in deSolve.

Key Takeaways

  • ODE models describe rates, not amounts.
  • Initial conditions matter: a different I₀ produces a different entire trajectory.
  • Numerical integration replaces the analytical solution.
  • Stiffness is common in epidemic models with large populations.
