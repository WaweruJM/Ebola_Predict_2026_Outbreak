The Daily Pipeline, Step by Step

This portal is not manually updated. Every day at 05:00 UTC, a GitHub Actions workflow pulls the latest upstream data, runs the SIR model, exports a JSON file, renders an R Markdown report, and publishes the whole site to GitHub Pages. Here is the entire workflow explained.

Step 1 — Data Preparation

The upstream repository (webbegole/ebola-bundibugyo-tracker-2026) publishes a CSV of daily case reports. The workflow clones that repository and copies data/timeseries.csv into the workspace.

Step 2 — Data Wrangling

  • Parses dates unambiguously.
  • Normalises column names.
  • Removes duplicate daily rows.
  • Computes derived columns: active cases, case fatality rate, daily incidence.

Only confirmed cases are used in modelling. Suspected cases are excluded because their reporting is far more variable.

Step 3 — Parameter Estimation

The SIR parameters (β, γ, μ) are estimated by non-linear least squares. The objective function is:

SSE(β, γ, I₀) = Σ [observed_cumulative(t) − predicted_cumulative(t)]²

where the model's cumulative output is I(t) + R(t) + D(t). The optimisation uses optim(method = "L-BFGS-B") with logarithmic reparameterisation to enforce positivity and box constraints to prevent impossible estimates.

Step 4 — Train / Test Split

  • Training (first 80 %): Used to fit β, γ, and I₀.
  • Testing (last 20 %): Held out entirely. The fitted model is evaluated on this window to measure predictive skill on data it has never seen.

Step 5 — Model Performance

  • RMSE — Root Mean Squared Error.
  • MAE — Mean Absolute Error.
  • R² — Coefficient of determination.

Step 6 — Projection

Once parameters are estimated, the ODE system is re-anchored at the state of the last observation and integrated forward for 14 days.

Step 7 — Export and Deploy

The script writes data/ebola_data.json. The R Markdown report is rendered to reports/dashboard.html. The workflow assembles the deployable site and publishes it to the gh-pages branch.

How to Reproduce Locally

# 1. Fetch the latest upstream data
git clone https://github.com/webbegole/ebola-bundibugyo-tracker-2026
cp ebola-bundibugyo-tracker-2026/data/timeseries.csv ./downloaded_timeseries.csv

# 2. Run the analysis
Rscript incremental_fetch.R

# 3. Render the report
Rscript -e 'rmarkdown::render("dashboard.Rmd", output_file = "reports/dashboard.html")'

# 4. Serve the portal
python3 -m http.server 8000
